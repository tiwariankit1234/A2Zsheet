## How links were verified

- **LeetCode** — every link is the one the reference sheet itself lists, and its slug was confirmed to exist in LeetCode's problem catalog (`/api/problems/all/`, fetched on the snapshot date). `implement-strstr` was updated to its current slug `find-the-index-of-the-first-occurrence-in-a-string`. Some reference links point to a related rather than identical LeetCode problem (e.g. *Leaders in an Array* → *Buildings With an Ocean View*); those are kept as the reference sheet lists them.
- **GFG** — the reference sheet has no GFG links. Each sheet problem was matched against GFG's practice catalog: an exact (normalised) title match with a single candidate, or a close match that was reviewed by hand. All 143 GFG URLs were then fetched from GFG's API and resolved to a real problem. Problems without a confident match have no GFG link rather than a guessed one.

- **Owner-supplied** — *Intersection of two sorted arrays* → [Intersection of Two Arrays](https://leetcode.com/problems/intersection-of-two-arrays/) was added by the project owner (slug confirmed in LeetCode's catalog).
